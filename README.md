# Дворик

Каркас недели 1. Godot 4.3+, 2D, renderer Compatibility.

## Открыть

1. Godot 4.3 или новее.
2. Import → эта папка `godot/` (`project.godot`).
3. F5. Портрет 1080×1920.

## Умеет

- Сетка 8×8 целиком на экране, без скролла и зума. Дом в (3,3).
- Палитра дом / дорога / дерево / вода. Дом уже в руке. Текста нет.
- Пустые клетки — трава. Тап: поставить / заменить. Тот же тип — тычок.
- Дом+дом по ортогональной стороне → улочка (общий конёк на общем ребре). Три в ряд — та же улочка длиннее.
- Первая улочка — вспышка лака один раз. Ввод не стопается.
- Автосейв `user://dvorik.save` после постановки/замены.

## Нет

Ластик, отмена, зум, меню, остальные пары (пруд, роща, крыльцо…), реклама, IAP, сервер, изометрия, физика, музыка, уровни.

## Критерий

Второй дом ортогонально к первому → улочка + вспышка один раз + сейв. Закрыла → открыла — тот же дворик, вспышка не повторяется.
